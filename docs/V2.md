# Version 2.0 — phase-by-phase plan

Independent open-source AI teammates with a shared computer. **Not affiliated with xAI, SpaceX, Grok, or Oracle OpenGrok.**

## Why a new name

The current GitHub repo is still `johnmatveyev-lab/grok-bot`. That name, the old “clone” copy, and any **Grok / xAI / SpaceXAI** product chrome need to go before a public 2.0 launch.

Keep using **xAI as an optional model provider** (same as OpenAI or NVIDIA). Supporting an API is not the same as shipping their product.

## Do not use OpenGrok domains

You found `opengrok.bot`, `opengrok.co`, and `opengrok.app`. DNS is empty today (likely unregistered), but they are a poor fit:

1. **Grok** is xAI’s product mark. “OpenGrok bot” still trades on that word.
2. **OpenGrok** is already a well-known Oracle/Sun **source-code search** project: [github.com/oracle/opengrok](https://github.com/oracle/opengrok) and `opengrok.org`.

Do not register those three for this product.
